## Current Use

The lab has tested two ICP accelerometer types, PCB Electronics ICP Model TLD352A56 and ICP Model 621C40, using NI DAQ hardware. These measurements can help compare structural vibration signatures with AE sensor, hydrophone, or microphone signals.
