# Microphone System

## Components

| Role | Hardware or Software | Notes |
| --- | --- | --- |
| Microphone | Behringer ECM8000 condenser microphone | Positioned close to the test section for exploratory airborne acoustic measurements. |
| Audio interface | Behringer U-PHORIA UMC404HD | Connected to the computer for microphone signal acquisition. |
| Power supply | Neewer NW-100 | Used to power the condenser microphone setup. |
| Software | NI LabVIEW | Used to collect microphone data. |

## Current Use

This system has been used as an exploratory acoustic sensing setup. The microphone is positioned close to the test section, connected through the Behringer U-PHORIA UMC404HD DAQ/audio interface, powered by the Neewer NW-100 supply, and logged on the computer through LabVIEW.
